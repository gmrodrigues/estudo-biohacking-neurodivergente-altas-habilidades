# Dados para saúde cognitiva de precisão

O catálogo organiza bases complementares; não presume existir uma coorte perfeita.
A pergunta é se relações entre fatores modificáveis e funcionamento diferem por
capacidade contínua e perfil neurocognitivo.

## Ordem de execução

O [plano da fase 1](PHASE_1_PLAN.md) define entregas e critérios de suficiência.

1. [Fundação analítica e provas de conceito](ANALYTIC_FOUNDATION.md).
2. [Primeiro ciclo longitudinal ABCD](ABCD_FIRST_CYCLE.md).
3. [Dicionário de construtos e harmonização](CONSTRUCT_DICTIONARY.md).
4. [Capacidade amostral e acessos](DATA_MODEL_AND_SAMPLE_CAPACITY.md).
5. [Hábitos, biomarcadores e suplementação](SUPPLEMENT_HABITS_DATA_CAPACITY.md).

## Fontes

[`sources.yaml`](sources.yaml) é o catálogo estruturado. Confirme versão, acesso
e termos antes de download. [`ACCESS_FROM_CODEX.md`](ACCESS_FROM_CODEX.md)
separa metadados públicos, arquivos abertos e dados controlados.
